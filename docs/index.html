📖 วิธีใช้งาน

1️⃣ เข้าสู่ระบบ

  • ใช้อีเมล + รหัสผ่านที่ทีมงานส่งให้ในห้องส่วนตัวของกิลด์
  • เข้าครั้งแรก ระบบให้ตั้งรหัสผ่านใหม่ (อย่างน้อย 8 ตัว)
  • ติ๊ก "จดจำฉันไว้ 30 วัน" จะได้ไม่ต้อง Login บ่อย (เครื่องที่ใช้ร่วมกับคนอื่นไม่ต้องติ๊ก)

2️⃣ ส่ง Report

  • แท็บ ส่ง Report → เลือก Mission → วางลิงก์หลักฐาน 1 กล่อง = 1 ลิงก์ → กดส่ง
  • หลายลิงก์: กด ＋ เพิ่มลิงก์ · วางหลายลิงก์ในกล่องเดียวระบบแยกให้เอง · หรือ 📂 นำเข้าลิงก์จากไฟล์ (.txt .csv .xlsx)
  • รูปหลักฐาน: กด 🖼️ เพิ่มรูป · ลากรูปมาวาง · หรือแคปหน้าจอแล้วกด Ctrl+V — 1 รูป = 1 กล่อง นับเหมือนลิงก์ (รูปเก็บเป็นความลับ ทีมงานเท่านั้นที่เปิดดูได้)
  • โพสต์ต้องเป็น สาธารณะ และติด Hashtag ตามกติกาของเกม
  • 1 ลิงก์ส่งได้ 1 ครั้ง · แต่ละ Mission มีจำนวนสูงสุดต่อเดือน (ดูในรายละเอียด Mission)

👥 รายชื่อสมาชิก

  • แท็บ สมาชิก → เพิ่มทีละคน · วางจาก Excel (ชื่อตัวละคร | ID ในเกม | Level) · หรือนำเข้าไฟล์ .csv / .xlsx → กด 💾 บันทึกรายชื่อ
  • ได้รับ Benefit เฉพาะสมาชิกที่ Level ถึงเกณฑ์ (แถบเขียว = ผ่าน) · ทีมงานล็อกรายชื่อทุกวันสุดท้ายของเดือนเพื่อแจกรางวัล

3️⃣ ดูคะแนน

  • แท็บ คะแนน → คะแนนเดือนนี้ · สะสมทั้งปี · อีกกี่คะแนนถึง Rank S / SS
  • แท็บ ประวัติ → 🟡 รอตรวจ · 🟢 อนุมัติ · 🔴 ปฏิเสธ (มีเหตุผลบอก แก้แล้วส่งใหม่ได้)
  • คะแนนนับเมื่อทีมงาน อนุมัติ แล้วเท่านั้น · นับรอบวันที่ 1 – สิ้นเดือน

❓ ลืมรหัส / เข้าไม่ได้

  • แจ้งทีมงานในห้องส่วนตัวของกิลด์ ทีมงานจะรีเซ็ตรหัสให้

💡 เพิ่มเว็บนี้ลงหน้าจอหลักมือถือได้: Android ⋮ → เพิ่มลงในหน้าจอหลัก · iPhone ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
